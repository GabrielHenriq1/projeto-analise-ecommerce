Análise de Vendas e Comportamento de Clientes

SQL (MySQL) | Power BI |

---

 Sobre o projeto

Projeto completo de análise de dados usando dados públicos de e-commerce (Olist). Foram analisadas 20 mil transações para responder perguntas de negócio como faturamento, ticket médio, produtos mais vendidos, perfil de clientes e sazonalidade.

O objetivo foi praticar SQL (consultas, agregações, subconsultas) e construir um dashboard no Power BI para visualização dos principais KPIs.
